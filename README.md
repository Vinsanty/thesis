# Интернет-магазин

Дипломный проект — полноценный интернет-магазин с корзиной, оформлением заказов и админ-панелью.

## Стек
- JavaScript
- React
- Redux
- Node.js
- PostgreSQL

## Возможности
- Регистрация и авторизация пользователей
- Просмотр каталога товаров
- Добавление товаров в корзину
- Оформление заказов
- Удаление товаров из каталога

## Архитектура
- **Frontend:** React + Redux
- **Backend:** Node.js (REST API)
- **База данных:** PostgreSQL
